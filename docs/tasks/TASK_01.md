## Deliverable
1. A coherent iOS 17+ native SwiftUI app with a reproducible Xcode project and shared Proximeet scheme. Prefer a checked-in deterministic project generator written in Python (no third party dependency) plus generated .xcodeproj, or a small hand-maintained project if demonstrably consistent. Keep DEVELOPMENT_TEAM unset, use an explicitly provisional bundle identifier such as com.proximeet.demo, and document that it must be registered under the owner's team before distribution. Do not inherit app.projecthalo.lab or any existing Apple credentials. No workflows, publishing scripts, analytics, remote dependencies or service calls.
2. A separate pure-Swift package, ProximeetDomain, supporting draft profile, birthday eligibility and scene transitions. No HaloCore copy. Target Swift 5.9-compatible language features with strict concurrency considered; installed Linux Swift is 6.3.3. Use platform-independent Foundation/XCTest or Swift Testing if tools version supports it.
3. Preserve Welcome → Birthday → Demo Pass → Guest List → Band → Signal → Ready for check-in. First four screens are honest functional scaffolds; concentrate material detail on B1/B2. This is an explicitly labelled DEMO. No real sign-in, age/identity verification, venue verification, presence, backend, Waves or chat. User-entered birthday is an eligibility check, never proof of age. Pass always says DEMO, never VERIFIED. Do not imply a successful external check or simulate verification with a timer.
4. Guest List collects first name and three interests, allows editing, uses entered profile data everywhere. Provide sensible validation, no hardcoded personal name. Birthday has an under-18 boundary test and future-date rejection; inject date/calendar for deterministic tests. Never retain DOB or profile beyond this in-memory demo run. Reset clears all personal draft data.
5. B1: four substantial woven bands, Social #35D7FF, Dating #FF56B8, Business #FFD542, Activity #70F455. Labels and recognizable icons, dark readable text on bright fill, textile detail, proper clasp and object-specific selection. Confirming reveals a secured pose; same band and selection persist into B2. Provide reusable material, fabric, clasp, tag, typography and control components. No old low-res wrist photograph. State changes are immediate and independent of decorative completion.
6. B2: four machined tag choices Come say hi / Chat first / With my crew / Just looking. Native legible labels plus brief neutral descriptive copy. Select seats the tag against the persistent band. Confirm goes to Ready for check-in with real draft profile, band and tag, plus "Demo — not visible to anyone". Edit links return to meaningful destinations and preserve draft values.
7. Band and signal are pre-check-in draft choices. Do not finalize when an intent locks, how groups work or approach enforcement. No policy claims beyond draft selections. Do not add venue entry. The reference's older "locks only when you join a session" copy is not ratified; omit.
8. Accessibility: native navigation and form interactions, Dynamic Type scaling, VoiceOver labels and selected state, 44pt minimum targets (primary 56pt), suitable wrapping/single-column tags at large sizes, contrast that does not depend on moving highlights, Reduce Motion parity with opacity-only/static alternatives, Increase Contrast and Reduce Transparency. Use appropriate SF fonts; note font substitution vs Barlow/Inter reference, pending native comparison.
9. Motion: band confirm 650–850 ms; tag attachment 450–650 ms. No countdown or input lock. Rapid reselection uses latest state; navigation does not await animation. Offscreen decorative work stops. Avoid always-running TimelineView loops and speculative Metal complexity in this first increment. Haptics only on deliberate local selection/contact, not simulated mutual-consent success.
10. Include SwiftUI previews or DEBUG launch arguments for direct B1/B2 inspection with explicitly fictional fixtures isolated from the real-data normal flow. Do not override get-only accessibility environment keys in previews.
